# FG Public School Boys — Kharian Cantt

Official website of **FG Public School Boys, Kharian Cantt**, built with the school's own real photographs — the main building, the Principal, the morning assembly, national-day celebrations, and the Kharian Region football team.

**Live website:** https://fg-public-school-kharian.vercel.app
**Code:** https://github.com/hamza0312615/FG-public-boys-school-kharian-cantt-website-

## What's inside

| File | What it is |
| --- | --- |
| `index.html` | The complete website in a single file — HTML, CSS, JS **and all 6 school photos embedded inside it**. No `assets/` folder needed, so it works as-is on GitHub Pages and in any browser. |
| `standalone.html` | An identical copy of the one-file version, kept as a backup. |

## Sections

- Hero — school building with a slow zoom and green gradient overlay
- About the school
- Principal's Message
- Academics — Primary · Middle · Matric
- Morning Assembly & Discipline
- Patriotism & National Days
- Sports — Kharian Region football team
- Photo Gallery — tap any photo to enlarge
- Admissions 2026 — close **31 March 2026**, classes commence **06 April 2026** (from the school's official schedule)
- Contact — Kharian Cantt location with Google Maps link

## Design

- Deep Pakistan green + white + warm gold palette
- Smooth scrolling, fade-up reveal animations, hover lift and photo zoom
- Sticky header, announcements ticker, mobile menu
- Fully responsive — no sideways scrolling on phones

## Run it locally

Open `index.html` in a browser — that's all, the photos are inside the file. The GitHub Pages version of this repo serves the same `index.html`.
